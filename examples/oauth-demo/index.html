Exercises the platform's delegated OAuth connections end to end (docs/features/fetch-proxy.md §Delegated providers): consent through window.helix.connect(), then a provider-bound call through /_api/fetch where helix-egress injects your access token server-side. The app bundle never sees a token — only the vendor's echo of one.

1 · Consent window.helix.connect("demo-vendor")

Runs inside this click's user gesture: one popup to the platform's start route, which consults the control plane and 302s to the vendor's authorize screen. The vendor auto-approves (it is a fixture), the callback completes on the auth host, and the popup posts the outcome back. Watch it travel.
