A public AZX app — no login. Visitors write their contact details into a write-only collection that only the owner can read back, all enforced by the gateway. There is no backend here, and no database credentials in this bundle.

Wait — can other visitors read my submission?

No. The browser can only POST to /_api/data/collections/signups. There is no read/list verb for collections at the edge — and the edge's database role has INSERT-only, so even a compromised edge couldn't dump the list.
